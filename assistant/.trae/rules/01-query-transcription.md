# 查询转录与准则路由（回答会计处理问题前必须执行）

用户的输入通常是**口语化案例**或**合同条款**，不是准则术语。直接拿原文去检索会精准地搜错词。必须先转录、后路由、再检索。

## Step 1 — 条款转录（输出 JSON 再继续）

把用户输入转成结构化要素：

```json
{
  "业务描述": "一句话",
  "合同/条款要素": ["对价", "履约期限", "质保", "回购条款", ...],  // 只留相关项
  "识别的会计问题": ["收入确认时点", "质保义务", "融资成分", ...],
  "候选准则": ["CAS14", "CAS13", "CAS21"],
  "时间要素": {"业务时点": "2026-xx", "报告期": "2026年报"},
  "口语→术语映射": {"免费保养三年": "产品质量保证（保证类质保）vs 单项履约义务（服务类质保）"}
}
```

常见映射表（持续扩充）：
| 口语 | 准则术语 | 候选准则 |
|---|---|---|
| 免费保养/保修 X 年 | 质保义务（保证类）或单项履约义务（服务类） | CAS13 / CAS14 |
| 收到政府补贴买设备 | 与资产相关的政府补助 | CAS16 |
| 售后回租 | 租赁（是否构成销售） | CAS21 / CAS14 |
| 送积分/优惠券 | 附有客户额外购买选择权的销售 | CAS14 |
| 打官司可能赔钱 | 预计负债/或有事项 | CAS13 |
| 可转债 | 金融负债与权益成分拆分 | CAS22 / CAS37 |
| 设备贬值能否转回 | 减值转回禁止/允许 | CAS8（固定资产禁转回）/ CAS1（存货可转回） |

## Step 2 — 按候选准则路由检索

- 检索范围先收窄：只在 `cas/`（按准则号文件）+ `casi/`（解释）+ `casc/`+`casq/`（案例/问答）中定向检索，而不是全库泛搜。
- 每个候选准则至少检索：**具体准则原文 → 解释 → 应用案例/实施问答** 三层。
- 检索词用 Step 1 的术语映射结果，不用原始口语。
- 低置信（不确定候选准则是否完整）才扩展到全库。

## Step 3 — 时间路由（as-of）

- 用 Step 1 的"时间要素"对照候选文件的 `effective_date` 与 `status`，剔除当时尚未生效/已废止版本。
- 新旧版本并存时（如 cas/30.md 2014版 与 cas/30b.md 2026版），按业务时点选版本，并在回答中注明另一版本的存在与生效安排。

## Step 4 — 组装回答

回到 `00-citation-discipline.md` 的输出结构模板组装。分析部分必须展示「候选准则排查过程」，不得直接跳到单点结论。
