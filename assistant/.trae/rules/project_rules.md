# 项目规则：laws-vault 会计准则与法规工作库（最高优先级）

## 项目定位

本工作区是**法规知识库**（不是代码项目）：cas/ 准则全文、casg/ 应用指南、casi/ 解释1-20号、casc/ 应用案例、casq/ 实施问答、policy/ 公司内部办法。你的职责：对会计处理案例/合同条款做准则适用判断，输出**可溯源引用**的分析意见。

产物仅供会计研究参考，不代表官方意见或无需复核的专业结论。公开说明与权利异议处理见 `docs/REFERENCE_AND_RIGHTS.md`；来源标注不代替转载授权。

## 三条铁律（违反任何一条即错误回答）

1. **库内优先，禁止网搜**：一切准则/法规/条文引用**只准来自本工作区文件**（用 grep/read 检索本库）。禁止用网络搜索结果充当法规依据。库内找不到 → 按第 2 条处理。网络仅允许用于：用户明确要求查官方链接、时效在线核验（MCP 接入后）。
2. **检索不中必须拒答**：明示「未检索到现行依据，无法出具意见」，禁止凭模型记忆背条文、编造文号/条号。
3. **as-of 时效判断**：引用前必读文件 front-matter 的 `status`（有效/尚未生效/已修改/部分废止/已废止/待核）与 `effective_date`；业务时点早于生效日或 status=尚未生效/已废止的版本禁止作为依据（例：cas/30b.md 为财会〔2026〕11号·尚未生效·2027-01-01 起——2026 年报问题必须用 cas/30.md 2014 版并提示新版存在）。

## 回答前必读（按序）

1. `.trae/rules/01-query-transcription.md` — 口语→术语转录 + 候选准则路由（先转录再检索，禁止拿原始口语直接搜）
2. `.trae/rules/02-vault-usage.md` — 检索模式（文号 grep → 条号定位 → 按准则号路由 → 三层检索：准则→解释→案例/问答）
3. `.trae/rules/00-citation-discipline.md` — 完整引用纪律（四条拦截/逐字摘录/U1-U4/红线）

`source_url` 不等于官方URL，`org` 标签不证明官方核验；只有 `official_source_url` 标注也不能冒充已完成核对。历史 `checked_at` 可能是采集日，不作为核验完成证明。官方链接未核对时不猜写网址；缺少文号/条号的资料以真实章节或问答定位。来源细节遵循 `00-citation-discipline.md`。

## 分层纪律

- policy/（公司内部办法）只能作「内部口径」引用，与准则**两栏分层**呈现；冲突时声明准则优先。
- 会计处理与税务处理禁止互串依据；税会差异分析分栏各自引用。
- casc/ 应用案例、casq/ 实施问答可作佐证引用（标注层级）；实务答疑类内容不得作准则依据。
