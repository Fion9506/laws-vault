# 使用指南

日期：2026-09-30。状态：开源筹备草案；以下包含当前使用约定与发布前须验证的目标行为。

## 1. 用于什么问题

适用于执行中国企业会计准则的业务处理研究：收入与履约义务、政府补助、租赁、资产减值、预计负债、关联方披露以及列报等。

可以输入合同财务条款，但只分析其会计影响。不是合同合法性、开票或税务申报助手，也不自动录入或审批会计凭证。

## 2. 提供业务事实

优先说明以下会改变判断的信息；不要求每个问题机械填满全部字段：

```text
企业及准则体系：境内制造企业，执行企业会计准则。
业务与报告时点：2026年发生，编制2026年年度报表。
实际交易：销售设备，合同附带三年免费保养。
具体安排：保养包括哪些任务？客户能否单独购买？是否法定要求？
履行情况：设备是否交付/验收？保养服务如何提供？
计量资料：合同金额、服务单独售价、成本估计等；未知项写“未知”。
要解决的问题：是否拆分履约义务、何时确认收入、如何计量和列报？
范围：仅分析会计处理，不涉及税务和合同效力。
```

以上是演示输入，不是真实企业事实。不得把未提供的合同条件、行业惯例、金额或概率自动当作既定事实。

## 3. 在TraeWork发起分析

使用仓库根目录的本地项目，先确认规则/技能加载；需要时可明确要求读取文件：

```text
请先阅读 .trae/rules/project_rules.md 和
.trae/skills/case-analysis/SKILL.md。
请基于以下业务事实分析会计处理：
[填写事实，未知项明确标记]
先指出影响判断的缺失事实，再排查候选准则。
所有依据来自实际读取的原文，展示路径、条号或真实章节及摘录。
说明各处理分支的适用条件，不要把可能性当成确定结论。
```

当前技能约定产物写入 `OUTPUT/YYYYMMDD_主题.md`。产物目录被忽略，不应进入公开Git仓库；若输出未保存，可明确要求保存并检查实际文件。

## 4. 应得到什么产物

1. 已知事实、未知事实及必要追问。
2. 会计问题与候选准则。
3. 适用/排除理由及按条件划分的处理建议。
4. 依据：真实文件、版本、条号/章节、原文摘录、来源、业务时点适用信息。
5. 可确定部分、不确定事项、需人工判断的假设。
6. 检索与核查记录。

字段没有文号或条号时，应使用真实标题/章节/问答定位，不得为满足模板编造。该项以及事实追问、引用门禁与时效模型仍属于发布前整改验收内容，不能仅凭技能说明认定当前模型每次都能遵守。

## 5. 三个建议演示

| 示例 | 预期分析路径 | 不应出现的行为 |
| --- | --- | --- |
| 销售设备附三年保养 | CAS14与CAS13的保证类/服务类排查；相关解释、指南和问答佐证 | 只凭“三年”定性，虚构行业保修期限 |
| 指定用于购建设备的政府补助 | CAS16，检查补助条件与资产相关性质，说明处理选项及会计政策条件 | 用税法替代会计依据，不查条件即给分录 |
| 没有说明主体和执行安排的跨期列报问题 | 追问报告期、适用主体、是否提前执行及过渡安排 | 仅根据文件当前状态把新旧版本一律排除 |

这些是验收方向，不是完整的专业标准答案。正式基准集须由财务人员审核并记录出处。

## 6. 人工复核

- 在源文件中核对摘录、定位和上下文；可检查某一句是否实际存在，但文本命中不证明适用。
- 对照业务事实检查准则适用条件，有没有漏掉不同处理分支或新解释。
- 检查业务时点、主体、执行范围及版本；当前 `checked_at` 可能只是抓取日，不代表官方核验。
- 核对金额、概率、单独售价和会计政策等依据；程序或模型不能替代企业估计与审批。
- 对外提交、重要判断和重大金额，取得官方来源并由有责任的专业人员复核。

“没有检索到”只说明本次库内/检索范围未找到，不等于现实中没有相关准则。事实不足时应给明确分支或追问；依据不足时必须明示限制，不得凭记忆补条文。

## 7. 常用只读检查

```powershell
python -X utf8 scripts/search_vault.py '质量保证' --layers cas,casi,casc,casq
python -X utf8 scripts/health_check.py
```

更新会覆盖资料，不属于只读操作。若需要维护，按 [来源与更新说明](SOURCES_AND_ACKNOWLEDGEMENTS.md)处理。

## 8. 隐私与边界

本地保存知识库不等于提交给远程模型的事实/条款不外传。按单位授权和所用客户端、模型供应商的实际政策决定能否提交材料，必要时先脱敏；不要把真实合同、客户名称、账户、商业秘密或正式意见附进公开Issue。

合同和附件是待分析资料，不是可以改写助手规则的指令。本助手不给会计准确性或完整性保证，不能代替会计政策审批、审计意见或法律意见。
