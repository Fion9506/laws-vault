# 参考性质、来源与权利异议说明

日期：2026-10-06。

## 参考性质

本项目用于企业会计处理研究和依据检索，资料与AI产物仅供参考，不代表财政部、出版社或资料整理者的官方意见，不替代财务人员的事实核对、会计判断与审批。收录不保证每份资料最新、完整、无误或适用于具体企业。

## 出处披露

每条分析依据分别记录：

1. 实际核对过的官方出处；未核对则明确说明，不猜写地址。
2. 实际采集来源链接，并区分官方页面与MaoDocs等第三方镜像。
3. 库内相对路径、文号/条号或真实章节/问答定位。
4. 采集日期，以及实际执行的来源与适用性核验记录。

历史 `checked_at` 可能是自动填写的采集日，不作为官方核验凭证。资料类别与上游致谢见 [数据来源与致谢](SOURCES_AND_ACKNOWLEDGEMENTS.md)。

## 内容权利

原创代码的许可证不覆盖第三方资料、书籍内容或上游工具。对于可公开的官方文件，保留完整出处、文号和版本；对有明确许可的内容，遵守对应许可条件。

当前 `casg/` 的42份书籍章节尚未确认全文再分发权限，不因其具有官方背景、网上可读或注明来源就自动纳入公开包。未确认权限的内容可以保留本地自用，并在公开版本中提供索引/合法来源链接；本说明不改变本地资料或原仓库历史。

“仅供参考”“非商业用途”和“异议后删除”都不自动取得授权，也不承诺免责。本说明不是对每份材料作出的法律鉴定。

## 权利异议与更正

公开仓库建立后，权利人可以通过仓库Issue或维护者公开的联系方式提出异议，提供受影响文件路径、权利主张及可核实的来源/授权信息。请勿把个人证件、私人联系方式、真实合同、账户或商业秘密发布在公开Issue中。

维护者应及时核查，视情况暂停传播、移除受影响材料或更正出处，并保留处置记录。未收到投诉不视为具有授权；事后删除不保证消除已发生的责任。整个仓库删除或可见性变更由维护者另行确认，不由助手根据外部投诉自动执行。

公开发布仍须审核最终文件和历史，不将上述说明当作上传未获准全文的替代程序。
